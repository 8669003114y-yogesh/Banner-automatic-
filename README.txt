(ॲप म्हणून इन्स्टॉल होण्यासाठी GitHub Pages सारखा वेब पत्ता लागतो, फाईल थेट उघडल्यास तो चालत नाही.)

GitHub वर टाकणे:
1. github.com वर नवीन repository बनवा (नाव banner-maker, Public).
2. आधीच्या फाईली असतील तर त्या बदला: "Add file" > "Upload files", पाचही फाईली टाका, Commit करा.
   (जुना icon.png असेल तर तो Delete करा.)
3. Settings > Pages > Branch: main > Save.
4. दोन मिनिटांनी your-username.github.io/banner-maker उघडा. वर "ॲप इन्स्टॉल करा" बटण येईल.
